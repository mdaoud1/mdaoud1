## Featured project

### [DrinkSync](https://github.com/mdaoud1/DrinkSync) · IEEE-published hydration tracker

A low-cost smart coaster that detects every sip and sends it to an Android app. Built as my Rutgers ECE capstone and published at IEEE.

- **What I built:** the Android UI, the gamification layer (streaks, achievements, milestone notifications) and the settings page
- **Stack:** Kotlin · Jetpack Compose · Python · Raspberry Pi · Bluetooth
